Connect your agent
to the north.

Takumi offers an MCP server: a compass an agent can consult for orientation. Read-only — readable, never steerable. Takumi weighs; it does not act.

An agent consults Takumi before it acts: it reads which element and which question lead the day, and lets that shape what it proposes. So you and your agent share the same north — and "less" becomes a valid answer when the season calls for it, not only "more".

The endpoint

https://app.takumi-master.com/mcp
Transport
Streamable HTTP (JSON-RPC 2.0)
Read-only
yes — resources only, no tools
Auth
none (public, non-personal data)
Cost
none — stateless, computed from the date

What you get

Four resources. All stateless: derived from the date and the source texts of Natuurlijk Agile. No accounts, no storage of your data.

ResourceReturns
takumi://pulse/morningThe day-leader (a Godai element) plus an inviting morning question.
takumi://pulse/eveningThe day-leader plus a reflective evening question.
takumi://reflectieOne reflection from Natuurlijk Agile, matched to the time of day.
takumi://noordenThe orienting line of the manifesto plus the day-leader as direction.

The day-leader rotates daily through the five elements — Chi (Earth), Sui (Water), Fū (Wind), Ka (Fire), Kū (Emptiness) — with the Master Council as synthesis. The same day yields the same leader and question, so you and your agent sit on the same north.

Try it (no client)

Open the URL in a browser for the server info, or call a resource directly:

# server info
curl https://app.takumi-master.com/mcp

# read a resource
curl -X POST https://app.takumi-master.com/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"resources/read","params":{"uri":"takumi://noorden"}}'

Connect from an MCP client

The server speaks standard MCP, so any MCP-compatible agent or client can plug in. Add it as a remote (HTTP) MCP server with the endpoint URL. Since there is no auth, no key or token is needed.

// generic client config
{
  "mcpServers": {
    "takumi": {
      "url": "https://app.takumi-master.com/mcp"
    }
  }
}

In a client with a UI, look for where to add a custom or remote connector (often under settings → connectors), choose "remote" or "URL", and paste the endpoint. Exact steps vary per product and may change; the URL stays the same. Your agent will then see four readable resources. No tools — that is not an omission, it is the choice.

How to use it

The idea is that an executing agent consults Takumi before it acts, as orientation. For example, at the start of a working day:

# in an agent prompt
Read takumi://pulse/morning. Which element leads today,
and which question does it ask? Keep that in mind when
you propose how to plan my day.

The agent navigates; Takumi holds the north. What the agent does with the orientation stays — as it should — a choice.

What it deliberately does not do

No tools. The server executes nothing, changes nothing, buys nothing. Reading only.

No personal data. The current resources are the same for everyone — the daily rotation and the reflections from the book. Your own direction (the season you are in) belongs to a later, authenticated version.

No storage of your requests. The server is stateless and does not log your calls as part of its working.

A compass, not a navigator. Readable, never steerable.
