Backup van jouw Takumi-data

Takumi slaat jouw data niet op een server op — alleen lokaal in deze browser. Maak regelmatig een backup naar een plek die jij kiest: iCloud, Dropbox, Google Drive, of gewoon je downloads.

Op mobiel opent de deel-knop direct je apps. Op desktop wordt het bestand gedownload.

Wat staat in een backup? Je doelen, ritme, HRV-historie, gesprekken met de Master Council, oefeningen in de Dojo — alles wat je in Takumi hebt opgebouwd. Niet inbegrepen: je Google-login (die regelt Takumi apart).
